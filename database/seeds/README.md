# Synthetic seeds

`pnpm db:seed:synthetic` inserts only deterministic LOCAL/TEST principals used by the
foundation harness. It refuses STAGING and PRODUCTION. No real person, provider, seller,
location promise, legal value, tax rate, commission, COD ceiling, or retention period is
seeded here.

Wilaya/commune data is intentionally absent until an authoritative source, checksum,
version, and maintenance owner are recorded.
